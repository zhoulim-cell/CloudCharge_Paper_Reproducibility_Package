# AGU / JGR Open Research text

The CloudCharge model used in this study is archived as version 5.0.0 in
Zenodo (Zhou, 2026a; https://doi.org/10.5281/zenodo.SOFTWARE_DOI). The actively
developed source code is available at
https://github.com/zhoulim-cell/CloudCharge_Paper_Reproducibility_Package.
The archived software is released under the MIT License.

The numerical model outputs and processed data supporting the figures, tables,
and Supporting Information are archived separately in Zenodo (Zhou, 2026b;
https://doi.org/10.5281/zenodo.DATA_DOI). The research data are released under
CC BY 4.0.
