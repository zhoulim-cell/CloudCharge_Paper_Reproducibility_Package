# AGU / JGR Open Research text

The CloudCharge model used in this study, including the charge-resolved ion,
aerosol, and droplet model, experiment configurations, validation material,
and analysis utilities, is archived as version 5.0.0 in Zenodo (Zhou, 2026a;
https://doi.org/10.5281/zenodo.23879986). The actively developed source code is available at
https://github.com/zhoulim-cell/CloudCharge_Paper_Reproducibility_Package.
The archived software is released under the MIT License.

The numerical model outputs and processed data supporting the figures, tables,
and Supporting Information are archived separately in Zenodo (Zhou, 2026b;
https://doi.org/10.5281/zenodo.23880373). The research data are released under CC BY 4.0.
