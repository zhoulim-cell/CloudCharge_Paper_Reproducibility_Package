# CloudCharge v5.0.0 — JGR Reproducibility Release

Initial public software release accompanying:

**Charge-Resolved Transient Electrification at Layer-Cloud Boundaries**

The release contains the charge-resolved layer-cloud electrification model,
tests, configurations, validation material, manuscript-level tables, and
reproducibility documentation.

Large primary numerical outputs and publication TIFF files are archived in a
separate Zenodo Dataset.
