# v5.0验证摘要

## 1. 600 s双谱—位移电流基准

参数：4 km层云，`Jz`在300 s由1.5增至3.0 pA m⁻²，云滴和气溶胶均采用粒径—电荷谱，含竖直涡扩散，不启用静电清除反馈。

结果：

- 云顶峰值平均云滴电荷：`+20.22 e`；
- 云底峰值平均云滴电荷：`-20.29 e`；
- 云顶积分空间电荷：`+7.32×10⁻10 C m⁻2`；
- 云底积分空间电荷：`-6.98×10⁻10 C m⁻2`；
- 上下边界云滴异号检验：通过；
- 上下边界积分空间电荷异号检验：通过；
- 内部网格最大相对高斯残差：约`1.76%`；
- 最大相对总电流残差：约`1.97%`。

开放边界最大绝对高斯残差仍较大，主要位于第一网格点。程序已将内部残差与边界残差分开报告。后续应由观测或外部柱电阻模型提供边界电势/场条件。

## 2. 合成观测反演

合成真值乘性参数：

- `Jz`: 1.30；
- 气溶胶浓度：0.75；
- 涡扩散系数：1.20。

6成员、2轮集合反演得到：

- `Jz`: `1.208 ± 0.036`；
- 气溶胶：`1.003 ± 0.133`；
- 涡扩散：`1.049 ± 0.158`。

该小样本试验说明电流尺度较易由现有合成观测识别，而气溶胶和湍流参数存在明显退化。它是观测设计演示，不是正式后验结论。

## 3. 拉丁超立方敏感性演示

10个样本中，云顶峰值云滴电荷的Spearman相关：

- 电流尺度：`+0.891`；
- 电离率尺度：`-0.321`；
- 气溶胶尺度：`-0.091`；
- 涡扩散尺度：`-0.358`；
- 云边界厚度尺度：`-0.321`。

样本量仅用于代码验证。正式论文建议至少使用100–500个样本，并增加结构不确定性试验。
